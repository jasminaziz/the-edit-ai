## Canva

**Current column E verdict, 338 characters:**

> The workhorse. Not the most exciting tool in the stack, but the one I use most consistently because it just works. The Claude Design integration for managing brand kits and templates is a recent upgrade worth setting up properly, and the AI Magic layer tools are genuinely strong. Not a gimmick, not a demo, actually usable in daily work.

**Original column L text, 424 characters:**

> This is a great user-friendly tool for creating unbranded, consistent designs on a budget. My best recommendation is always getting a brand designer to create reusable branded templates for Canva that can then be utilised by the team as branded templates. Instead of every campaign having to pay for new designs from a designer. This empowers the team to make their own and the AI tools in Canva make this particularly easy.

## ChatGPT

**Current column E verdict, 335 characters:**

> The right tool for brainstorming and thinking out loud, especially inside a Project with memory turned on and reference documents built in. Set it up properly once and it becomes a genuine thinking partner rather than a slightly better search engine. Custom GPTs are worth the time if you find yourself repeating the same prompt shape.

**Original column L text, 518 characters:**

> This is a brilliant brainstorming tool, as out of all the LLMs, it's trained on the most amount of textual data, so it has the widest capture of knowledge. However, the governance here is important, as I would never put sensor data, donor information, or financial reporting data straight into this tool to format. I would much rather use something like Microsoft Copilot that sits on our tenancy to do this. I don't use this as my main copywriting tool, but I do use it as a very powerful brainstormer and researcher.

## Microsoft Copilot

**Current column E verdict, 300 characters:**

> Embedded AI across Microsoft 365. Word, Excel, Outlook, Teams. The draft-and-summarise workflow in Outlook and Word is where it earns daily use, and calendar integration is genuinely useful for anyone running meeting-heavy weeks. Worth having if M365 is your work environment; skippable if it is not.

**Original column L text, 712 characters:**

> The reason to use this tool over Claude for work tasks is data governance, not capability. When working with sensitive information, client data, HR matters, anything confidential, Copilot keeps that data inside your organisations own Microsoft tenancy rather than sending it to a third-party cloud. That is a real distinction that matters in practice, and one I would flag to any comms director working in a regulated or public sector environment. It is not my favourite tool to use, but it is the right tool for the context. It's also a great way to have a tool that can work across SharePoint documents and Microsoft emails at the same time, so it can be a great way to build first drafts of trustee reporting.

## DeepSeek

**Current column E verdict, 596 characters:**

> Chinese open-source AI lab producing frontier-quality models at very low cost, and the pace has not slowed. V4-Flash exited preview on 31 July 2026, priced at a fraction of a cent per million tokens and benchmarking close to Claude Opus 4.8 on coding and agentic tasks despite being the lighter model in the family. The full V4-Pro release originally expected in June has slipped, worth knowing if you were waiting for it specifically. Free to use at deepseek.com, and the strongest argument yet that frontier coding capability is becoming a commodity rather than something you pay a premium for.

**Original column L text, 440 characters:**

> The reason to choose this tool over others is primarily for its low cost and strong reasoning performance, which helps stretch tight non-profit budgets. Although API price adjustments means operating costs can change over time, it is still priced at a fraction of a cent per million tokens. Importantly, because the model weights are open, charities can host the software locally or use secure third-party options to protect sensitive data.
