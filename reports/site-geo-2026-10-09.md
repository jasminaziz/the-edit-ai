Run 9 October 2026, curl only, user agent "site-geo audit (jasminaziz.co.uk)", one second between fetches. Purpose: interview preparation. No earlier site-geo report exists in reports/, so no scores moved. No facts sheet and no approved question set were supplied.

Evidence floor: Methodology v1, 3 September 2026. That is 36 days before today, inside the three-month re-check window.

## Verdict

1. **Can answer engines reach the priority pages?** Yes at the gate, no in substance. Robots.txt allows every named bot, every sitemap URL returns 200 with no X-Robots-Tag and no robots meta tag. But raw curl returns an empty page body on all 11 sitemap URLs (see "Rendering finding"), so there is nothing for a crawler to read or cite.
2. **How do the pages score?** Not scored. The content scorecard cannot run on any page: the raw HTML carries no body text. Owner of the rendering finding: **site-gates**. I have not diagnosed it.
3. **Single edit that would move the most:** whatever site-gates finds necessary so that curl returns body text on the priority pages. Until then every row in the scorecard (Row: Direct quotations from named people or sources on the page; Row: Statistics with a stated source; Row: Cited sources; Row: A passage that answers the sub-question directly; Row: Plain, fluent, readable prose; Row: Keyword stuffing and repetition) scores nothing, because there is no passage to score.

## Method notes

- Fetched 9 October 2026 (15:11 to 16:12 BST) with curl, GET only, user agent "site-geo audit (jasminaziz.co.uk)", one-second gaps. Public records only: theeditai.co.uk, Companies House search, MediaWiki and Wikidata APIs, Charity Commission register. No Google, ChatGPT, Perplexity, LinkedIn, Reddit, Quora or YouTube fetch.
- Scores come from raw curl HTML only. Raw HTML is what answer-engine crawlers receive, as none execute JavaScript.
- Firewall blind spot: a firewall or CDN that blocks bots by user agent is invisible from robots.txt. The site is served by Vercel and my honest user agent was not blocked, but I cannot see how other bots are treated, so the Check 1 passes are for the rules in robots.txt only.
- Scoring anchors (section A defines none; these would have applied): 0 absent; 1 present but thin (unattributed, a single instance, or buried below where the page makes its main claims); 2 present and carrying the page's main claims. Not applied, because no page had a body.
- Fan-out scores are provisional whenever no approved question set exists. None were produced this run.
- No timestamps or cache headers were used to infer page changes.
- Evidence floor dated 3 September 2026 (Methodology v1); next quarterly re-check due by early December 2026.
- Schema markup, JSON-LD and llms.txt are not scored: section A marks them Not a lever.
